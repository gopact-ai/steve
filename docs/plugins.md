# 能力包

能力包把一组技能、MCP 服务和 agent 预设放在一起，让项目能够复用同一套工作方法和工具。控制台「插件」页管理导入、节点配置、启用、升级与移除。

能力包服务于 agent 的运行环境；邮件和 GitHub 这类独立事件进程使用[Provider 接口](events.md)。安装能力包不会自动启动事件订阅。

## 选择与安装

包来源可以是本地目录或固定 Git 提交。导入前查看清单、执行文件、服务地址、设置和凭据用途，再选择项目。准备操作保存固定内容，不执行安装脚本，也不安装新的 harness。

安装配置包含项目范围、目标机器、普通设置和节点凭据引用。每台机器检查自己的平台、解释器与凭据，控制台分别显示准备结果。启用后，匹配项目和机器上的新会话可以使用这些能力。

Agent 预设提供 harness、模型偏好、指令和包内能力引用。在页面预览后应用，可新建 agent 或显式采用已有 agent。预设不提供模型账号或机器访问权。

## 包、安装和会话

| 对象 | 保存什么 |
| --- | --- |
| 包 | 固定版本、内容摘要、技能、MCP 定义和预设 |
| 安装 | 启用状态、项目和节点范围、普通配置、凭据版本引用 |
| 会话运行环境 | 实际使用的包摘要、技能内容、配置、MCP 路由和原生状态 |

同一个包 ID/版本只能对应同一份内容。发布改动使用新版本，节点按摘要准备。跨节点准备需要集群协调者；独立 Hub 可管理自身部署。

凭据保存在执行节点，协调端仅选择名称和修订引用。普通设置不能代替 secret 字段。包本身是可信代码，安装目录不是操作系统沙箱。

## 升级、回退与移除

升级和回退修改新会话使用的默认版本。已有会话、空闲原生会话与待恢复执行保留原摘要和运行目录；缺少原内容时恢复会阻塞，不自动换成最新版。

停用阻止新绑定，不自动终止已有执行。撤销项目或节点范围会拒绝后续准入和接回；已发出的外部请求无法撤回。

移除前，控制台列出仍引用该安装的会话和节点。关闭空闲原生会话会保留对话记录；活动回合、失联节点和停止未确认的引用会阻止移除。确认无引用且进程退出后才回收运行目录，包库和操作历史保留。

不要手动删除运行 home：里面既有固定技能和 MCP 配置，也有可恢复的原生会话状态。

## 已有技能和 MCP

显式采用已有 agent 时，可以逐项把旧技能路径与 MCP 名称映射到包能力。模型、指令和无关能力保留，用户原目录及机器服务不删除。其他 agent 仍可使用原资源。

移除安装保留 agent 当前用户配置，解除预设来源，不自动恢复旧引用。技能与 MCP 页面中的插件条目链接回相应安装，配置在安装页维护。
