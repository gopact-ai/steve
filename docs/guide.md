# 日常使用

工作台是你与 agent 一起处理项目的地方。项目确定文件和访问范围，会话保存讨论，任务记录执行及结果。

## 项目和 agent

每个项目有一个主目录，可在其他机器声明工作区。目录属于项目；agent 是一份命名配置，包含执行机器、harness、模型偏好、技能和 MCP 服务。实际可用工具与模型由执行机器报告。

新会话选择项目后开始工作。`/project use <name>` 切换项目，`/use <agent>` 选择 agent，`@` 和 `/` 提供补全。切换项目不会把既有任务迁走。`/new` 创建新的原生 agent 上下文，适用于需要重新装配技能或插件的会话。

Agent 可使用全局和项目记忆。全局记忆保存用户约定，项目记忆保存项目约定；新 owner 私聊或控制台会话在首轮读取。群聊、访客与委派子任务不能写入这些私人记忆。

## 发送和补充材料

Enter 发送，Shift+Enter 换行。执行期间的普通消息进入队列；输入草稿和待确认提交保存在当前 App 或浏览器中，未发送的草稿不属于服务端任务。

材料可以来自上传文件、对话文本、源码或 Diff 行范围，以及图片选区。发送时引用内容被固定，之后源文件变化不会改变原输入。标记按项目保存。选中回复或代码可以加入主对话，也可以在独立侧聊中提问。

同一草稿在多个窗口发生冲突时，界面保留输入并提示选择版本。本地保存失败时先复制重要内容；本地草稿不随集群复制。

## 权限与提问

Agent 的工具权限请求和补充问题直接出现在等待中的回合里。你的回答送回原执行，无需排在任务队列之后；取消或拒绝不会执行相应调用。

全局默认审批在设置中选择，agent 可以配置自己的原生审批选项，会话也可单独设置。优先级为会话、agent、全局默认、工具默认。默认值在打开或恢复原生会话时应用；保存设置不打断正在执行的任务。

`ask`、`auto`、`full` 表达审批意图，Steve 根据工具实际提供的模式映射。工具权限策略约束经 ACP 发出的请求，不能替代执行环境自身的沙箱。项目角色和数据等级仍独立参与准入。详细字段见[配置参考](configuration.md#默认审批策略)。

客户端能力的审批及结果不明的外部动作出现在「待处理」。审批授权一次操作；收到请求、agent 完成和外部操作完成是不同状态。

## 委派与任务

Agent 可以把有明确目标的工作委派给其他 agent。子任务有自己的执行记录，共享父任务剩余预算，受委派深度与环检测限制。子任务结果持久保存后，Steve 在父会话可继续时送回结果；父 agent 无需持续轮询。

任务看板显示进展、阻塞和结束状态。展开任务可查看子任务、执行机器、产物和用量。同一个目标可能经历多次执行，恢复后的记录仍可追溯到原任务。

「停止」或 `/cancel` 停止当前回合及仍运行的委派子任务。任务列表中的暂停保留继续入口，取消为终止操作。节点无法确认进程退出时，界面保留停止待确认状态，相关目录不会立即交给替代执行。

关闭窗口不会停止后台任务。连接中断或服务重启后，Steve 核对原执行回执再尝试续接；恢复需要你决定时，会显示原因和可用选项。见[中断与恢复](desktop.md#中断与恢复)。

## 文件与结果

回复下方的变更卡片汇总文件与增删行，打开后可查看文件树、源码及 Diff。「代码」入口可以切换执行快照。查看器是只读的，内容来自选中执行的开始或结束版本。

普通交互直接使用执行机器上的项目主目录或副本，设置 `repo: isolated` 也不会自动隔离普通对话。委派和计划步骤使用隔离工作区。隔离结果需要合并回主目录。任务执行完成并不表示文件已经落地：目录忙碌时排队，合并失败时显示冲突，按对应记录处理。

影子快照包含符合收录规则的未提交文件，不改变源仓库的分支或提交。快照有文件数量和大小限制；被截断的读取不代表完整内容。

## 计划、事件和定时工作

`/plan` 用于需要分步执行的目标。计划可表达依赖、并行和验证；工作结果与落地状态保留在原任务中。规划器和验证 agent 使用相同的权限、预算和执行记录。

`/at` 与 `/every` 创建一次性或周期工作。外部事件也可以通过订阅交给会话处理，例如新邮件摘要或 PR 检查分析。使用方法见[事件订阅](events.md)，agent 可通过 `steve_help` 查询当前平台工具的参数。

## 用量、历史和显示

用量页按 1d、7d、30d 查看 token、耗时及 agent、模型、项目等分组。Token 总量为输入加输出，缓存读取和写入单列。未上报与上报零消耗分别记录；图中零值不证明没有消耗。根任务耗时按父子执行时间区间合并，避免并行工作重复计时。

历史页提供任务、执行、审批和机器操作记录。资源页展示机器在线情况与 agent 可用性；程序存在、模型登录有效和任务能通过准入分别核对。

设置支持简体中文、English 和跟随浏览器，以及独立的配色、界面字体、阅读字体与代码字体。显示设置保存在当前客户端，不改变对话正文或服务端项目。HTML 产物可在隔离预览中阅读；依赖本地文件、登录或原生窗口能力的页面可能需要单独运行。
