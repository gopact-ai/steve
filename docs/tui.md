# 终端客户端

在终端里直接执行 `steve`（或 `steve tui`）会打开交互式客户端。它通过 [`steve.client.v1`](protocol.md) 与 Steve 服务通信，会话、任务和提问都保存在服务端；关闭终端不会停止正在执行的任务，其他客户端（App、网页控制台）看到的是同一份会话。

## 连接

不带参数时，客户端使用本用户由 `steve init` 或桌面 App 创建的本地安装。服务未运行时，它按 `steve desktop` 的方式在后台启动服务，再连接。还没有本地安装时先执行 `steve init`。

连接用 `steve run` 启动的独立服务时，与 `steve top`、`steve say` 一样传入连接参数：

```sh
steve tui -config /srv/steve/config.json
steve tui -url http://127.0.0.1:7710 -token <console token>
```

| 参数 | 含义 |
| --- | --- |
| `-thread <id>` | 打开指定会话，不存在时创建；默认打开最近的控制台会话 |
| `-project <id>` | 新建会话绑定的项目；默认使用服务端的默认项目 |
| `-state-dir <dir>` | 本地安装目录，默认是用户的应用支持目录 |
| `-timeout <duration>` | 等待本地服务启动的时间，默认 30s |

`steve` 只有在标准输入和输出都是终端且没有任何参数时才打开客户端。带 `run` 或任何参数、或不在终端中执行时，行为与 `steve run` 相同，服务管理器和桌面 App 的启动方式不受影响。

## 界面

顶部显示会话、项目、agent、执行机器和连接状态。中间是会话记录：你的消息、Steve 的回复、工具调用、文件变更和提问；回合执行时实时显示计划、工具和正在生成的回答。底部是状态行和输入框。

| 按键 | 作用 |
| --- | --- |
| Enter | 发送 |
| Shift+Enter、Alt+Enter、Ctrl+J | 换行（部分终端不区分 Shift+Enter，可用后两者） |
| Ctrl-C | 停止正在执行的回合；再按一次退出 |
| Ctrl-D | 退出 |
| Ctrl-T | 切换会话或新建会话 |
| PgUp、PgDn、鼠标滚轮 | 滚动会话记录；提示框有焦点时 PgUp、PgDn 滚动提示框 |

以 `/` 开头的输入是 Steve 命令，与网页控制台一样由服务端执行，例如 `/help`、`/use <agent>`、`/project use <name>`、`/new`。执行期间发送的消息进入队列。发送失败时输入保留在输入框，再按 Enter 以同一个提交标识重试，服务端不会重复执行。

## 权限与提问

Agent 请求工具权限或提出问题时，输入框上方出现提示框并获得键盘焦点：↑/↓ 选择，Enter 确认所选项，`d` 拒绝，`c` 取消。允许自由回答的问题可以选择「Write an answer…」输入文字；输入文字时第一次 Esc 离开答案框，之后可用 `d`、`c`。内容超出屏幕时提示框限高，所选项保持可见。Esc 暂时回到输入框，问题保持等待，Tab 回到提示框。回答与网页控制台使用同一套规则，已在其他客户端回答的问题会自动关闭。

## 断线与重启

连接中断或服务重启时，顶部显示 `reconnecting`，客户端按退避间隔自动重连，并从收到的最后一个事件继续。服务无法从该位置继续时（例如重启后），客户端重新读取当前会话；会话记录始终以服务端为准，不会出现重复条目。

## 当前限制

- 回复按纯文本显示，不渲染 Markdown。
- 会话记录显示最近 200 条。
- 不支持附件、引用和改写已发送的消息；这些操作在 App 或网页控制台中进行。
- 连接使用控制台 token，经本机回环地址或你指定的 URL 访问。
