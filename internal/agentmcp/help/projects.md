# 项目与工作区

项目声明主目录、工作方式、数据等级、授权、技能和可选工作区。会话绑定项目，实际目录由执行机器与执行类型决定。用 `steve_context`、`steve_projects` 和当前工作目录核对。

| 目录 | 行为 |
| --- | --- |
| 主目录 | 项目的合并目标；inplace 交互在此直接修改 |
| 副本 | 其他机器上的已声明工作区；普通修改保留在副本，需要显式同步 |
| 隔离树 | 委派、计划和验证的工作目录，结果通过产物及落地处理 |

回合快照按收录规则保存未提交文件，供审阅和内容传输使用，不代替工作区备份。副本修改不自动回到主目录；有授权时通过 Git 同步，否则说明尚未同步的状态。

计划步骤遵守 touches 路径和输入引用，merge 步骤可读 `inputs/<步骤>/`。工作区外访问受工具和执行环境限制，不假设任意 agent 程序都被平台沙箱覆盖。

## 项目不在当前机器

使用已有工作区所在机器的 agent，或按授权添加本机副本、切换项目。在本机临时创建目录不等于声明了项目工作区，也不能据此宣称结果会回到主目录。

`/project` 查看当前项目，`/project use <id>` 切换会话绑定；原任务仍属于创建时项目。`/grant <project> <who> <role>` 设置 none、read、write、admin 角色，需符合调用者的当前权限。

## 数据等级

等级为 public、internal、restricted、sealed。机器等级必须覆盖项目；sealed 内容限制在主机器，不提供跨节点副本。能力符合也不能绕过数据放置规则。共享完整账本的集群不承载 sealed 项目。
