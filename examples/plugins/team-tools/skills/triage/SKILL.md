---
name: team-triage
description: Investigate a specified project issue using an authorized team MCP endpoint.
---

Establish the affected project, symptom and relevant time range. Read available
issue and diagnostic evidence, then separate confirmed facts from hypotheses.
Return the likely cause, supporting evidence and a concrete next check.

Mutating issues, changing services and sending notifications require the
corresponding authorization. Missing evidence is an unresolved question, not
proof that an operation succeeded. Keep credentials and unrelated project data
out of the response.
