---
name: github-review
description: Review a specified GitHub pull request against its base and the project's requirements.
---

Read the requested PR, its diff and relevant project instructions. Identify
reproducible defects and missing verification, including the trigger and impact
of each finding. Distinguish observed results from untested hypotheses.

Use GitHub tools within the project's authorization. Preparing findings does not
by itself authorize posting, approving or merging a PR. Return findings through
Steve's normal result path; the platform records execution and delivery.
